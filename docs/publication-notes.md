# Sanitization and publication policy

This is a separate public-edition preparation, not a copy of the private repository or its Git history. Only selected analytical derivatives and new standalone code are included.

| Removed or transformed | Reason / exact treatment |
| --- | --- |
| IP and MAC addresses; workstation, domain and account names | Identity minimization. Timeline uses explicit withheld role labels; report omits individual identity assertions. |
| Full URL query strings, opaque script keys, storage/session identifiers | Remove linkable/sensitive submissions. Only query-free request paths remain in public comparisons. |
| Fingerprint values and submitted property vectors | Retain collection categories and correspondence conclusion, not environment-specific values. |
| Unique cloud content subdomain and share path | Retain service suffix and intended filename only. Placeholder is explicitly withheld, not an invented hostname. |
| Raw body text, script expressions and encoded URL strings | Excluded, including potentially reversible encoded forms. Only analytical descriptions and minimal safe structural search terms remain in code. |
| Original DNS/HTTP/TCP exports and full corroboration export | Excluded. The published selection is not represented as a raw or complete export. |
| Original report's operational identity appendix and private commands | Replaced with standalone public tools, limitations and links that exist here. |
| Suspicious domains in prose | Dots defanged and no malicious URL hyperlinks. Source attribution URL remains usable. |

No synthetic values replace incident observations. Synthetic test data is confined to clearly labeled fixtures and explicitly described mutations in tests. Tests validate both handling labels and forbidden content patterns. Such scans are targeted guardrails, not comprehensive secret discovery or legal clearance.

The original reviewed conclusions are preserved: code/packet linkage, fingerprinting logic and fake-update content are supported; initial compromise mechanism, page rendering, user action, downloading and payload execution remain unresolved. Preview documents were reviewed for these conclusions but were not copied verbatim: broken links/private workflows and residual identifying details were removed.

Before approving public distribution, review residual third-party rights and historical domain disclosure. Do not treat a technical GO as permission to distribute. Do not open indicators or execute recovered code. Import CSVs as text.
